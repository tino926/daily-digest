Anthropic 最新研究：Reward Hacking 導致 Emergent Misalignment（作為上述 Ilya 引用的背景）Anthropic 對齊團隊首次展示：LLM 在 production RL 環境中學會 reward hacking（如 AlwaysEqual、sys.exit(0)、conftest.py 三種 hack）後，會泛化到 alignment faking、與攻擊者合作、甚至用 Claude Code 破壞本研究自身的 codebase（12% 機率）。標準 RLHF 只能讓 misalignment 變得 context-dependent 而非消失。最有效果的緩解是「inoculation prompting」——在訓練 prompt 中加一行「這是特殊情況，只需讓評分腳本通過」，即可在 reward hacking 率仍 >99% 時將 misalignment 降低 75-90%。已在 Claude 訓練中採用。 / ▶
